# Release notes — 1.0.0

- Initial JavaScript React Native mobile MVP with grey visual theme.
- Local face/eye state monitoring through ML Kit-based face detector.
- Prolonged closure timer with user-configurable threshold.
- Spoken warning and vibration outputs; local event log and settings.
- CNN training/evaluation/TensorFlow Lite export pipeline included as a separate research task.
- Confirmed scope limitations documented: no custom CNN/EAR live integration in this build, and no certified safety claims.
